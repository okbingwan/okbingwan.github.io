# 담양 옥빈관 웹 소개서

`index.html` 한 장으로 된 소개 페이지입니다. 외부 라이브러리 없이 HTML·CSS·약간의 JS만 쓰며, 사진은 `images/`에 있습니다. 이 폴더만 그대로 올리면 웹사이트가 됩니다.

```
okbingwan-site/
├── index.html          소개 페이지 (단일 파일, 55KB)
├── README.md
└── images/             사진 10장 (총 3.2MB)
    ├── tteokgalbi.jpg      한우 떡갈비 (히어로·대표 음식)
    ├── daetongbap.jpg      대통밥
    ├── saeujang.jpg        간장 새우장
    ├── table-spread.jpg    한 상 차림 전체 (매장 로고 사진)
    ├── table-hall.jpg      홀 상차림
    ├── table-closeup.jpg   상차림 클로즈업
    ├── garnish.jpg         가지튀김(밑반찬)
    ├── exterior-day.jpg    주간 외관
    ├── exterior-night.jpg  야간 외관 (간판)
    └── menu-board.jpg      매장 메뉴판
```

미리보기 파일은 상위 폴더 `옥빈관-소개서-미리보기/`에 따로 두었습니다(PDF 17쪽, 전체 화면 PNG). 배포용 폴더에는 넣지 않았습니다.

## 미리보기

```bash
cd okbingwan-site
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 발행(공개 링크) 방법

1. **GitHub Pages** (가장 간단)
   ```bash
   cd okbingwan-site
   git init -b main && git add . && git commit -m "옥빈관 웹 소개서"
   gh repo create okbingwan-site --public --source=. --push
   gh api -X POST repos/{owner}/okbingwan-site/pages -f 'source[branch]=main' -f 'source[path]=/'
   # 1~2분 뒤 https://<계정>.github.io/okbingwan-site/ 공개
   ```
2. **Netlify Drop** — https://app.netlify.com/drop 에 `okbingwan-site` 폴더를 끌어다 놓으면 즉시 주소가 생깁니다(무료, 계정 필요).
3. 발행 후 **네이버 플레이스 '홈페이지' 항목**을 새 주소로 바꾸면 검색 유입이 이 페이지로 옵니다(현재는 스마트스토어로 연결).

## 페이지 구성

히어로 → 주요 수치 → 옥빈관 이야기(오너셰프 소개글 기반) → 떡갈비 맛있게 먹는 법 → 대표 음식 → 전체 메뉴·가격 → 공간·단체·편의시설 → 고객 후기·인증 → 오시는 길·지도 → 마무리.

- 모바일: 상단 메뉴, 하단 고정 `전화 / 네이버 예약` 바, 한 열 카드
- 데스크톱 1440px·태블릿 768px에서 가로 스크롤 없음(렌더 검증 완료)
- 구조화 데이터(JSON-LD Restaurant), OG 태그, 인쇄용 스타일 포함

## 남은 확인 사항

- **창업 연도**: 매장 표기 "since 2006" vs 공공데이터 영업신고 2008-04-04 → 페이지에는 연도를 쓰지 않고 "20년 가까이"로 표기.
- **홀·룸 내부 사진**이 없어 외관·상차림 사진으로 대체. 매장에서 직접 찍은 사진으로 교체 권장.
- **사진 저작권**: 현재 사진은 구글 지도 방문자 제공 사진. 하단에 출처를 적어 두었으나, 매장 보유 사진으로 바꾸는 것이 가장 안전합니다.
- **영업시간**: 매일 10:30–20:30(라스트오더 20:00)으로 표기. 구글 지도는 화요일만 20:00 마감으로 다르게 표시.
- **OG 이미지**는 상대경로(`images/tteokgalbi.jpg`)입니다. 도메인이 정해지면 절대 주소로 바꾸면 카카오톡·문자 공유 썸네일이 정확해집니다.
